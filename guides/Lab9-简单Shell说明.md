# Lab9：简单 xv6 Shell

## 设计

新增的 `user/nsh.c` 不使用 `malloc()`。每次读入一行到固定的 1024 字节栈
缓冲区，执行函数直接在该缓冲区内把空白、`<`、`>` 和 `|` 改为字符串终止符，
并在栈上建立最多 9 个参数的 `argv`。因此解析所得指针只在本次 fork 出的命令
进程存活期间使用，不需要动态分配或回收命令树。

普通命令调用 `exec()`；失败信息及 `@ ` 提示符都写到标准错误，避免影响测试
程序捕获的标准输出。输入重定向关闭 fd 0 后以只读方式打开文件，输出重定向
关闭 fd 1 后以 `O_CREATE|O_WRONLY` 打开文件。

遇到管道时，shell 建立 pipe 并创建两个子进程：左侧把标准输出复制到写端，
右侧把标准输入复制到读端。两个子进程都关闭未使用的两端；父进程同样关闭两端
并等待它们结束，故不会保留写端而导致读端不能看到 EOF。每条输入命令再由主
循环 fork 一次执行，保证 shell 自身继续可读下一行。

## 验证

```sh
make clean
make qemu
```

在 xv6 中运行：

```sh
testsh nsh
```

本地结果为 `simple echo`、`simple grep`、两条命令、输入/输出重定向、双重
重定向、普通管道、管道加重定向、重复命令共九项全部 `PASS`，最终输出
`passed all tests`。
